Getting you running.

Thanks for being willing to try this. This page walks you through everything — every click, every line to copy, even the boring bits. If you've set up software before, parts of it will feel over-explained. If you haven't, that's the point. Plan on 20–30 minutes the first time; five seconds every time after that.

TavernOS runs on your own computer and uses Anthropic's AI to do its thinking. None of your data leaves your machine except the specific questions you ask the AI. You'll need an Anthropic account with about $10 of AI credit added (you won't spend most of it) and — if you're on Windows — about 30 minutes. If you hit anything that doesn't match this page, email contact@TavernOS.ai and I'll jump on a call.

This is a pre-alpha. Things will occasionally misbehave — that's normal for early software. The most useful thing you can do is tell me when something surprises you, good or bad. We'll do a 15-minute check-in at the end of week 1 and a short debrief at the end of week 2.
On a Mac? The install is similar but a few commands differ. Rather than have you guess, email contact@TavernOS.ai and I'll walk you through it on a 15-minute call. The instructions below are written for Windows 10 or 11.

01 Download TavernOS

Click the button below. Your browser downloads a file called tavernos-alpha.zip — by default it lands in your Downloads folder.

Download TavernOS ZIP · latest alpha ↓

Now unzip it:

  • Open File Explorer (click the yellow folder icon in your taskbar, or press the Windows key + E).
  • Click Downloads in the left sidebar.
  • Find tavernos-alpha.zip in the list. Right-click it → Extract All… → click Extract.
  • A new folder called tavernos-alpha appears in Downloads. You can close any windows that pop up.

02 Install Python

Python is the programming language TavernOS is built on. If it's not already on your machine, install it now — it's free, takes about two minutes, and is safe to leave installed afterward.

  • Open python.org/downloads in your browser.
  • Click the large yellow button that says Download Python 3.XX (any version 3.12 or newer).
  • When the download finishes, open the file — it will be in your Downloads folder and named something like python-3.12.X-amd64.exe.
Critical checkbox. On the first screen of the Python installer, look at the bottom for a checkbox that says "Add python.exe to PATH". Tick this box before clicking anything else. If you skip it, the rest of this guide won't work and you'll have to reinstall Python to fix it.
  • Click Install Now. Wait for it to finish (about 2 minutes).
  • Click Close when it says "Setup was successful."

Already had Python installed? That's fine — the installer will tell you, and you can close it without doing anything.

03 Open PowerShell

PowerShell is the text-based window you'll type commands into. It's built into Windows, you just need to open it.

  • Click the Windows Start button in the bottom-left corner of your screen (the Windows logo).
  • Type PowerShell — as you type, results appear above the search bar.
  • Click Windows PowerShell in the results. A dark-blue window opens showing white text.
  • Leave this window open — you'll use it for all the remaining steps.

The text in PowerShell will look intimidating but it's just where commands go. You're going to paste a few things into it. That's it.

04 Go to the TavernOS folder

You need to tell PowerShell which folder to work in. Copy the line below, paste it into PowerShell, and press Enter.

cd $HOME\Downloads\tavernos-alpha

To paste into PowerShell: click the Copy button on the code block above, then right-click anywhere inside the PowerShell window. Right-click is how PowerShell pastes. Press Enter after.

If it worked, the prompt at the bottom of PowerShell now ends with tavernos-alpha>. If it says "Cannot find path" or similar, the unzipped folder landed somewhere else — email me and we'll sort it.

05 Install TavernOS

Copy the entire block below in one go. Paste it into PowerShell (right-click to paste) and press Enter. It runs all four commands in sequence.

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser -Force python -m venv .venv .\.venv\Scripts\Activate.ps1 pip install -r requirements.txt

A lot of text will scroll past. This is normal — it's downloading the pieces TavernOS needs. Wait until text stops scrolling and the prompt comes back (ending in tavernos-alpha>). Usually 1–3 minutes depending on your internet speed.

You'll also notice the prompt now starts with (.venv). That means you're in the right environment. Good sign.

06 Get your Anthropic API key

TavernOS uses Anthropic's Claude AI for its thinking. You need an Anthropic account with a small amount of credit added. Budget about $10 — you'll use maybe a dollar during the trial; the rest stays on your account.

  • Open console.anthropic.com in your browser.
  • Click Sign up (or Log in if you already have an account). Verify your email if asked.
  • Once you're in, click Plans & Billing in the left sidebar → Add to credit balance → add $10 and pay.
  • In the same left sidebar, click API Keys.
  • Click the Create Key button.
  • Give it a name you'll remember — "TavernOS" works.
  • Click Create. A long string starting with sk-ant- appears.
  • Click Copy next to the key. Paste it into a Notes app or sticky note — you can't see the full key again once you close this page. Don't worry if you lose it; you just create a new one.

07 First run

Go back to PowerShell. Type this and press Enter:

python norm.py

TavernOS will start up and ask you to paste your API key (the one starting with sk-ant-).

  • Right-click inside PowerShell to paste your key.
  • Press Enter.
  • You're in. You'll see a welcome message and a prompt where you can type.

08 Try it

You're now talking to Sam, a coordinator who routes your request to the right specialist agent. Try one of these by typing it and pressing Enter:

  • build me a short proposal for a $5k operational audit engagement
  • Cliff, research SMB project-management tool adoption in creative agencies
  • /eval last — shows a score for the most recent deliverable
  • /scores --deliverables — lists everything TavernOS has produced
  • /exit — quits (you can come back anytime, see Step 10)

Finished deliverables land in this folder on your computer:

C:\Users\YOUR_USERNAME\.tavernos\clients\_self\deliverables\

Open them in Word, Excel, or whatever opens .docx / .xlsx / .pptx files. Tell me what's good, what's wrong, what's weird. That's the whole trial.

09 Prefer a browser? Try web mode

If you'd rather use TavernOS in a browser tab instead of PowerShell, type this into PowerShell (after Step 07 has finished at least once) and press Enter:

python norm.py --web

A browser tab opens with the same agents, same commands, but a chat-window interface instead of text-in-a-terminal. PowerShell stays open in the background while this runs — close PowerShell and the web page stops working. Pick whichever interface you prefer; you can switch run-to-run.

10 Using TavernOS next time

Once it's installed, coming back is three commands. Copy them one at a time — each after the previous one finishes.

cd $HOME\Downloads\tavernos-alpha .\.venv\Scripts\Activate.ps1 python norm.py

The second command activates the environment we set up in Step 05. The third starts TavernOS. Use python norm.py --web for the last line if you want the browser version.

11 If something goes wrong

Most common issues and what to do:

  • "python is not recognized…" — Python didn't get added to PATH in Step 02. Reinstall Python from python.org and make sure to tick the "Add python.exe to PATH" checkbox.
  • "Cannot find path… tavernos-alpha" — the unzipped folder landed somewhere other than Downloads. Email me and include where you actually unzipped it.
  • Red "Execution Policy" error — Step 05's first line didn't run. Copy just that one line (Set-ExecutionPolicy…) and paste it into PowerShell by itself, then re-try Step 05.
  • "Invalid API key" or authentication errors — go back to console.anthropic.com, create a new key, and use that one. Make sure you didn't copy extra spaces.
  • Anything else, or anything that looks scary — screenshot the PowerShell window and email it to contact@TavernOS.ai. I'll jump on a call with you.

12 What to tell me

Three things I care about most, in rough order:

  • Where did TavernOS say something confidently that was wrong? That's the most important bug.
  • Where did it refuse to help when it should have? Or help when it shouldn't have?
  • Anything that annoyed you enough to make you close the window.

Email, text, voice memo, annotated screenshot — whatever's easiest. I'll schedule a 15-minute check-in at the end of week 1 and a short debrief at the end of week 2.

13 Known rough edges

Things I already know don't work well; no need to report these:

  • No multi-user support. This is a single-operator tool right now — you and the machine.
  • No cloud sync. Deliverables live on your computer only. Back up the .tavernos folder in your user home if it matters to you.
  • Slack integration is teased on the public landing page but not yet real.
  • The AI evaluator occasionally disagrees with humans about quality. You can calibrate it — ask me how on the onboarding call.
